# Done checklist (human-eye rules)

Run `npm run audit` first for the mechanical ones. Then, on the contact sheets and one full watch of each cut,
with sound:

- [ ] Rule 1: read the captions alone, in order. They tell the whole story. One thing moves at a time.
- [ ] Rule 1: no frame asks the eye to look at two places.
- [ ] Rule 3: every caption is shown, not only said: the product does what the sentence claims.
- [ ] Rule 3: no screenshot, no real customer data, no number without a source.
- [ ] Rule 4: the display face fits the subject; the words the story points at are readable on a phone.
- [ ] Rule 7: no grey fog between scenes; starts and stops are eased; the hero moment comes once, late.
- [ ] Rule 7: the camera never moves a caption while it is read.
- [ ] Rule 8: each sound sits on its event; no idle motion makes noise; the end chord rings out.
- [ ] Rule 9: frame 0 of each cut works as a thumbnail; the 9:16 cut is designed, not cropped.
- [ ] Rule 9: watched muted, the film still makes sense.
- [ ] Rule 10: zoom on every sheet cell for small marks: a logo in a chip, a name in a breadcrumb, an id.
- [ ] Reviewed by someone who did not build it (a clean-context agent, before anything leaves the company).
