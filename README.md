# amir-motion

A Claude Code skill for making product launch films in Remotion, like the Soren film: one sentence per step,
the product showing instead of explaining, sound locked to the picture, FR/EN versions in 16:9 and 9:16. It
ships with a ready-made project template and an audit that blocks the film until the rules are met.

It builds on two existing skills, installed from their official sources:

- [`stageshow`](https://github.com/benjitaylor/skills) for the on-screen product UI (framing, restraint,
  cursor);
- [`remotion-best-practices`](https://github.com/remotion-dev/skills) for using Remotion (project, Studio,
  rendering).

## Install

Requirements: Node 22.18 or newer (Node 24 LTS recommended), Claude Code.

Everything in one line (amir-motion, stageshow and the Remotion skills):

```bash
npx skills add amirlehmam/amir-motion -g -a claude-code -y && npx skills add benjitaylor/skills --skill stageshow -g -a claude-code -y && npx skills add remotion-dev/skills --skill '*' -g -a claude-code -y
```

Or amir-motion alone: on first use, the skill runs `scripts/doctor.mjs`, which installs stageshow and the
Remotion skills if they are missing.

```bash
npx skills add amirlehmam/amir-motion -g -a claude-code -y
```

Check the installation at any time:

```bash
node ~/.claude/skills/amir-motion/scripts/doctor.mjs --check
```

Restart Claude Code after installing so the skills load.

### With Pi

```bash
npx skills add amirlehmam/amir-motion -g -a pi -y
node ~/.agents/skills/amir-motion/scripts/doctor.mjs
```

The doctor installs stageshow and the Remotion skills for both Claude Code and Pi. Restart Pi, then run
`/skill:amir-motion`, or just ask "make me a launch film for <product>".

On Windows PowerShell, write `node $HOME/.agents/skills/amir-motion/scripts/doctor.mjs`.

## Usage

In Claude Code: `/amir-motion`, or just "make me a launch film for <product>".

The skill walks through:

1. Doctor: checks the machine and the skills it calls.
2. Brief and breakdown: one line per step, approved before any scene is built.
3. Project generated by `scripts/new.mjs`: Remotion, FR/EN, 16:9 and 9:16, synthesized score.
4. Product scenes built with the stageshow rules.
5. Contact sheets, audit, render mastered at -14 LUFS.

By hand:

```bash
node ~/.claude/skills/amir-motion/scripts/new.mjs C:/Users/me/acme-motion --name "Acme" --forbid "Former Client" --install
cd C:/Users/me/acme-motion
npm run score    # music and sound effects, generated from the timeline
npm run dev      # Remotion Studio
npm run stills   # 16:9 and 9:16 contact sheets
npm run audit    # the gate
npm run finish   # renders every version, with mastered sound
```

On Windows, keep the project path short: headless Chrome will not start past 260 characters.
